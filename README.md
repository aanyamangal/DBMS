# 📚 DBMS — Database Management Systems

A collection of Database Management Systems (DBMS) laboratory exercises, SQL implementations, PL/pgSQL resources, and a capstone project.

This repository contains coursework and practical implementations exploring database concepts, SQL operations, and database-backed application development.

## 📂 Repository Structure

```text
DBMS/
├── CAPSTONE-PROJECT-OEMS/
├── LAB 1/
├── LAB2/
├── LAB3/
├── LAB4/
├── oems/
└── 2501730123_PLpgSql.pdf
```

## 📌 Contents

- **LAB 1 – LAB 4:** DBMS laboratory exercises and practical implementations.
- **CAPSTONE-PROJECT-OEMS:** Capstone project related to an OEMS system.
- **oems:** Project-related files and implementation resources.
- **PL/pgSQL PDF:** Reference material for PostgreSQL procedural SQL.

## 🛠️ Technologies & Concepts

- SQL
- PostgreSQL
- PL/pgSQL
- Database Design
- Database Management Systems
- SQL Queries and Operations
- Database Lab Practicals

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/aanyamangal/DBMS.git
```

### Navigate to the project directory

```bash
cd DBMS
```

Explore the lab folders, SQL files, and project resources to review and run the respective database exercises in a compatible database environment.

This repository serves as a collection of DBMS academic practicals and project work, documenting the application of database concepts through SQL and database-oriented implementations.
